# Figure Guide

논문 삽입용 그림은 이미지 내부 제목을 제거했고, 파일명은 한글 설명형으로 정리했다.

## Figure 1. `01_댓글_필터링_통과율.png`
**그림 역할:** 최종 감성 분석 표본이 연도별로 충분히 확보되었는가
**논문 인사이트:** 연도별 최종 댓글 수와 독성 가중치 적용 후 유효표본을 함께 보여 주어, 감성 피처가 특정 연도에만 과도하게 의존하지 않는지 확인한다.
**해석 포인트:** 막대는 최종 감성 분석에 사용된 댓글 수, 선은 독성 가중치 반영 후 유효표본 수다. 두 값의 차이가 크면 독성/노이즈 조정 효과가 큰 연도다.
**본문 연결:** 이 그림은 `01_댓글_필터링_통과율.png` 파일을 사용하고, 논문 본문/캡션에서 제목을 따로 부여한다.

## Figure 2. `02_독성점수_가중치_함수.png`
**그림 역할:** 독성 점수를 제거가 아니라 가중치로 반영한 이유
**논문 인사이트:** 본 연구는 독성 점수가 높을수록 댓글 영향력을 완만하게 낮추는 gamma=2 가중치를 사용한다.
**해석 포인트:** x축은 독성 점수, y축은 감성 계산에 반영되는 댓글 가중치다. 0.95 이상은 hard drop 후보 구간이다.
**본문 연결:** 이 그림은 `02_독성점수_가중치_함수.png` 파일을 사용하고, 논문 본문/캡션에서 제목을 따로 부여한다.

## Figure 3. `03_감성점수_정규화_전후.png`
**그림 역할:** 감성 점수 정규화가 필요한 이유
**논문 인사이트:** 원 점수는 0 부근에 지나치게 몰려 있어 시장 심리 변화를 충분히 드러내지 못한다. 정규화 후에는 음/양 방향 변동성이 살아난다.
**해석 포인트:** 왼쪽은 원 감성 점수, 오른쪽은 정규화 점수다. 오른쪽 분포가 더 넓으면 모델이 감성 변화를 피처로 사용할 여지가 커진다.
**본문 연결:** 이 그림은 `03_감성점수_정규화_전후.png` 파일을 사용하고, 논문 본문/캡션에서 제목을 따로 부여한다.

## Figure 4. `04_댓글수와_감성추세.png`
**그림 역할:** 감성 데이터의 양과 방향성이 시간에 따라 유지되는가
**논문 인사이트:** 댓글 수와 정규화 감성의 월별 흐름을 함께 보아 감성 피처의 시계열 안정성을 확인한다.
**해석 포인트:** 막대는 월별 댓글 수, 선은 월별 평균 감성이다. 댓글 수가 충분하고 감성 방향이 시간에 따라 움직이면 피처로 사용할 근거가 생긴다.
**본문 연결:** 이 그림은 `04_댓글수와_감성추세.png` 파일을 사용하고, 논문 본문/캡션에서 제목을 따로 부여한다.

## Figure 5. `05_KFGI_공포탐욕_시계열.png`
**그림 역할:** K-FGI가 공포/탐욕 구간을 어떻게 식별하는가
**논문 인사이트:** K-FGI는 0~100 스케일에서 낮을수록 fear, 높을수록 greed로 해석한다. 25/65 기준선은 극단 구간을 보는 참조선이다.
**해석 포인트:** 보라색 선은 20일 이동평균 K-FGI다. 파란 음영은 fear, 붉은 음영은 greed 구간이다.
**본문 연결:** 이 그림은 `05_KFGI_공포탐욕_시계열.png` 파일을 사용하고, 논문 본문/캡션에서 제목을 따로 부여한다.
