# 누수 없는 재실험 결과 요약 (2026-09-26)

## 설계
- 타이밍: s일 장 마감까지의 정보(그날 댓글 포함) → s+1일 종가에 거래 → s+2일 수익률. 이전 파이프라인은 s+3일(이중 지연).
- 누수 차단: 라벨(이후 5거래일)이 결정 시점까지 모두 실현된 표본만 학습(s ≤ t−6), 표준화·0에서 100 변환·심리 배수 방향을 과거 자료로만 결정, EGARCH는 실패·1e-4 미만·0.20 초과를 60거래일 표준편차로 대체(26/2,689일)하고 전체 표본 99.5% 상한은 쓰지 않음.
- 개발 구간 2016-01-06부터 2023-06-30까지(1,842일)에서만 선택, 봉인 구간 2023-07-01부터 2025-12-22까지(603일)는 한 번만 평가.
- 편도 3bp. 시도한 설정 482개.

## 재현 확인
새 코드로 논문 파이프라인(누수 포함, s+3 지연)을 재현하면 전체 기간 Sharpe 0.687, MDD −20.7% (논문 0.679, −20.55%).

## 결론
1. 누수를 막으면 성과가 낮아지고, 어떤 방법도 같은 노출의 정적 전략을 통계적으로 이기지 못한다(봉인 구간과 전체 기간 모두 신뢰구간이 0 포함).
2. 복잡한 모델(LightGBM, RF, XGBoost)과 강화학습은 변동성·손실 예측력이 EGARCH보다 낫지 않다. 강화학습은 시드마다 결과가 크게 달라진다.
3. 482개 시도를 고려한 deflated Sharpe 확률은 개발 구간 최고 후보도 0.71로 0.95에 못 미친다.
4. 일관되게 나타난 것: K-FGI 구성 요소 중 감성이 가장 유용하다(누수 여부, 목표 변수와 무관). 목표를 수익률에서 변동성으로 바꾸면 K-FGI가 좋아진다. 한 번만 지연하는 타이밍이 이중 지연보다 낫다. 회전율 조절(구간 0.3)은 모든 후보에서 개발 구간 성과를 높였다.

## 추가 분석 (2026-09-26 오후)

### 1. 미리 정한 규칙을 주 결과로 (step6)
논문 원래 설계에서 누수만 막고 한 번만 지연(회전율 조절 없음), 2016-01-06부터 2025-12-22까지 전체가 표본 밖. EGARCH는 지수별로 다시 추정했고, 전체 표본 99.5% 상한 대신 "최근 60거래일 실현 변동성의 3배 초과 시 추정 실패로 대체" 규칙을 사용(KOSPI 200에서 2016년 초 3일).

### 2. 다른 지수 (step6, 편도 3bp, Sharpe)
| 지수 | K-FGI 전체 | 감성 제외 | 감성만 | 정적 = B&H |
|---|---:|---:|---:|---:|
| KOSPI 200 | 0.522 | 0.568 | 0.631 | 0.501 |
| KOSPI | 0.388 | 0.388 | 0.522 | 0.440 |
| KOSDAQ | 0.137 | 0.030 | 0.242 | 0.135 |
(수익률 목표. 변동성 목표에서도 감성만이 세 지수 모두 1위.)
- 정적 전략 대비 Sharpe 차이: 모든 지수·설정에서 신뢰구간 0 포함.
- Buy & Hold 대비 CVaR 개선: 모든 지수에서 유의. 최대낙폭 개선: 11에서 34%p지만 신뢰구간이 0을 살짝 포함.
- 감성만 − 전체 Sharpe: 6개 경우 모두 양수(0.045에서 0.185), KOSDAQ 변동성 목표만 신뢰구간이 0 초과. 두 지표의 일별 비중 상관 0.90에서 0.94.

### 3. 예측 오차 검정 (step7, Diebold-Mariano, HAR+EGARCH 기준)
감성·서브 인덱스를 더해도 5일 변동성, 5일 VaR 5%, 큰 손실 확률 어느 것도 예측이 좋아지지 않음(손실 변화 −3.2%에서 +0.5%, 개선 유의한 경우 없음).
해석: 감성의 기여는 위험 예측 정확도가 아니라 노출 신호를 느리고 안정적으로 만드는 데서 나온다(회전율이 낮아지고 추세·변동성과 겹치지 않는 정보).

### 4. 감성의 기여 경로 검증 (step8, 미리 정한 규칙, 전체 기간)
- 가짜 감성(1년 이상 순환 이동, 40회): 진짜/가짜 평균 Sharpe KOSPI 200 0.631/0.600(p=0.29), KOSPI 0.522/0.459(p=0.12), KOSDAQ 0.242/0.113(p=0.049). 가짜만으로도 K-FGI 전체(0.522/0.387/0.137)보다 높음.
- 감성 없는 K-FGI 10일 평활: 0.549/0.436/0.126로 감성만에 못 미침 → 느린 움직임만으로는 설명 안 됨.
- 비용 0에서도 감성만이 1위(0.686/0.580/0.295) → 회전율 절약만으로 설명 안 됨.
- 추세 가중과의 순위 상관: 감성 없는 K-FGI 0.24에서 0.52, 감성만 0.00에서 0.06.
- 결론: 규칙에 이미 추세 가중이 있어 추세와 같이 움직이는 서브 인덱스는 추세를 이중 반영해 성과를 낮춘다. 감성은 추세와 겹치지 않아 이 문제가 없고, 내용이 약간의 정보를 더한다(KOSDAQ에서 유의).
